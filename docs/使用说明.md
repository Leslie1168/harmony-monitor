# 使用说明

桌面悬浮窗，通过无线方式实时监控多台鸿蒙设备的运行状态。
界面为深色玻璃风格，支持四种显示模式自由切换。

## 一、启动与退出

从源码跑：

```bash
.venv\Scripts\python main.py
```

打包版直接双击程序目录里的 `HarmonyMonitor.exe`。

- 首次启动因内置浏览器内核，会慢 1~2 秒，属正常
- 拖动窗口任意空白处可移动位置，位置会被记住
- 托盘图标右键：显示 / 隐藏、设置、退出
- 程序单实例：已经开着时再启动一次，只会把已有窗口唤到前台

## 二、四种显示模式

| 模式 | 样子 | 怎么进 / 怎么出 |
|---|---|---|
| **标签页**（默认） | 单台设备卡片 + 顶部设备标签 | 顶部「完整 / 标签 / 迷你」切换 |
| **完整面板** | 多台设备卡片并排 | 标签页右上「扩展 ⤢」，或顶部切换 |
| **迷你** | 350×190 小玻璃卡，三个圆环 | 顶部切换；右上「⇄」可弹菜单四选一 |
| **三台并排** | 多张迷你卡片并排 | 迷你右上「⤢」；顶栏「收起 ⤡」或顶部切换回 |

四种模式两两互通，从任何模式都能一步到任何其他模式。

## 三、迷你模式

- **切换设备**：点左上角的设备名标签
- **自定义名称**：双击标签输入昵称（最多 6 个字，回车保存，Esc 取消），重启保留
- **📌 固定**：窗口始终置顶在桌面上，随时可见；再点一次取消。固定时不影响其他按钮
- **悬停详情**：鼠标放上去，底部滑出温度 / Wi-Fi / 存储 / 运行时长
- **状态表现**：指标超标时圆环变色（黄 → 红），严重超标的环会呼吸闪烁；
  充电时电量环外圈有流动光点；设备离线时整卡变灰但保留最后一次数值

## 四、设备连接：两种通道

程序会自动识别设备类型，你只需要填对地址：

| 设备类型 | 典型系统 | 连接通道 | 地址形态 |
|---|---|---|---|
| 鸿蒙 4.x | HarmonyOS 4.2 / API 12 | **adb** | `192.168.1.23:5555` |
| 鸿蒙 7 及以上 | OpenHarmony 7 / API 26 | **hdc** | `192.168.1.24:43891` |

### 鸿蒙 4.x 设备

这类设备的开发人员选项里**没有「无线调试」开关**，必须先用 USB 一次性开启 TCP 端口：

1. 用数据线连接电脑，设备上确认「允许 USB 调试」
2. 双击程序目录内的 **`开启无线调试.bat`**，脚本自动对所有 USB 设备执行 `adb tcpip 5555`
3. 看到 `Done` 提示后拔掉数据线
4. 在设置里添加 `设备IP:5555`

设备 IP 查看方式：设备 设置 → WLAN → 点击当前网络。

> **设备重启后无线连接会失效**，需要重新插线运行一次 `开启无线调试.bat`。
> 这是 adb 无线调试的固有限制，鸿蒙 4.x 没有免重启的无线配对机制。

### 鸿蒙 7 / NEXT 设备

1. 设置 → 关于本机 → 连续点击「软件版本」7 次，开启开发者模式
2. 设置 → 系统和更新 → 开发人员选项 → 打开 **无线调试**
3. 页面显示的 `IP:端口` 直接填入即可

首次连接时设备会弹「允许调试」确认框，必须点允许。

## 五、设置与监控项

打开设置的两种方式：

- 标签页 / 完整面板模式：点右上角 `⚙`
- 任意模式：托盘图标右键 → 设置

「监控项」区域勾选后保存立即生效，共 5 组、29 项：

| 分组 | 可选项 |
|---|---|
| 设备 | 设备名称、型号、系统版本、API 版本、UDID |
| 性能 | CPU 使用率、CPU 负载、CPU 频率、CPU 温度、内存使用率、已用 / 可用内存、存储使用率、剩余存储、进程数 |
| 电池 | 电量、电池温度、电压、电流、充电状态、电池健康、充满剩余时间 |
| 网络 | Wi-Fi 名称、信号强度、链路速率、本机 IP |
| 系统 | 运行时长、屏幕亮度、分辨率 |

未勾选的项目不产生采集开销（迷你模式例外：为保证圆环和悬停详情，CPU / 内存 / 电量 /
充电状态 / 温度 / Wi-Fi / 存储 / 运行时长会始终采集）。

### 两种通道的字段差异

| 字段 | hdc（鸿蒙 7） | adb（鸿蒙 4.x） |
|---|---|---|
| CPU 温度 | 取不到（星盾限制） | **可读**（thermal_zone0） |
| CPU 频率 | 可读（每核） | 取不到 |
| 电压 / 电流 | 可读 | 电压可读，电流取不到 |
| 充满剩余时间 | 可读（实测常为 0） | 取不到 |

取不到的项显示 `—`，不影响其他指标。

## 六、采集频率

| 档位 | 间隔 | 覆盖指标 |
|---|---|---|
| fast | 1 秒 | CPU、负载、内存、存储、进程数 |
| mid | 5 秒 | 电池、Wi-Fi、IP |
| slow | 30 秒 | 运行时长、CPU 温度、屏幕亮度 |

## 七、常见问题

**显示「离线」**
设备休眠锁屏后无线调试可能断开，唤醒设备即可。程序会自动重连，持续失败才标记离线；
离线时迷你模式变灰但保留最后一次数值，方便对比。

**鸿蒙 4.x 重启后连不上**
重新插 USB 线，双击 `开启无线调试.bat`。

**地址变了**
设置里删旧添新。路由器 DHCP 通常会保留同一 IP 较长时间。

**双击快捷方式图标还是旧样子**
Windows 图标缓存固执。注销重新登录，或等一会儿自动刷新。

**程序占用的磁盘 / 内存比以前大**
界面用了内置浏览器内核（Chromium），安装目录约 570M，运行内存也更高——
这是为了实现玻璃质感界面的代价。

**日志**
程序异常退出时，查看同目录下的 `monitor.log` 与 `worker.log`。

## 八、目录结构（打包版）

```
HarmonyMonitor.exe        主程序
开启无线调试.bat           鸿蒙 4.x 设备恢复无线用
config.json               设备与外观配置（自动生成，可手动改）
app_harmony.ico           程序图标
monitor.log / worker.log  运行日志
hdc\                      鸿蒙调试工具链
tools\adb\                鸿蒙 4.x 调试工具链
_internal\                Python、Qt 与浏览器内核运行库（勿删，含界面文件）
```
